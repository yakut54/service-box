# Правила работы — читать обязательно

## Главное

- **Никакой самодеятельности.** Задан вопрос — отвечай на вопрос. Не бросайся писать код пока не попросили.
- **Если есть несколько вариантов** — предложи варианты, жди выбора.
- **Вручную ничего не деплоить** — деплой происходит автоматически через GitHub Actions после пуша.

## Проект

- **Шоперы** — наши клиенты (владельцы магазинов, используют админку)
- **Байеры** — клиенты шоперов (покупатели, используют виджет)
- **Таймзона** настраивается в админке каждым шопером. Всё что связано со временем опирается на неё.
- Пользователь — электрик, не разработчик. Объяснять сложные вещи простым языком.

## Код

- Избегать копипасты. Не должно быть одинаковых кусков кода.
- Переиспользовать готовые компоненты.

## Git

- Коммит и пуш делает Claude в ветку `flutter-app` на https://github.com/yakut54/service-box/tree/flutter-app
- После пуша автоматически срабатывает деплой (см. deploy.sh)
- Коммиты — только на английском (feat:, fix: и т.д.)
