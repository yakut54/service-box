# 🚀 ServiceBox

**SaaS-платформа для создания интернет-магазинов и систем бронирования**

ServiceBox — это современная мультитенантная платформа на Laravel 11 + Vue 3, которая позволяет владельцам бизнеса создавать свои онлайн-магазины и системы записи с минимальными усилиями.

## 🎯 Основные возможности

- ✅ **Multi-tenant архитектура** — изоляция данных на уровне PostgreSQL schemas
- 🛒 **Интернет-магазин** — физические товары, цифровые товары, услуги с бронированием
- 📦 **Заказы и клиенты** — полноценная CRM-система
- 💳 **Платежи YooKassa** — приём оплаты онлайн
- 📲 **Telegram-бот** — уведомления о заказах и бронированиях
- 🔧 **Embeddable Widget** — встраиваемый виджет для любого сайта
- 📊 **Админ-панель** — управление товарами, заказами, клиентами

## 🛠 Технологии

**Backend:** Laravel 11, PostgreSQL 16, Redis, Sanctum
**Frontend:** Vue 3 + TypeScript, Tailwind CSS, Pinia, Vite
**Infrastructure:** Docker, Traefik, n8n
