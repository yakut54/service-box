Введение

ServiceBox API позволяет управлять данными вашего магазина из любого внешнего приложения — CRM-системы, Telegram-бота, сайта на Tilda, Google Sheets через n8n/Make, или собственного кода.

Базовый URL всех запросов:

https://yakut54.ru/api/v1

API возвращает JSON. Все запросы и ответы используют кодировку UTF-8.

API доступно только на тарифе Pro. Ключ находится в AdminPanel → Настройки → Интеграция.

Аутентификация

Каждый запрос должен содержать заголовок X-API-Key с вашим API-ключом. 

# Пример
curl -X GET "https://yakut54.ru/api/v1/ping" \
     -H "X-API-Key: ваш-ключ" \
     -H "Accept: application/json"

Ошибки аутентификации

401Ключ не передан или не найден в системе
403Ключ валиден, но тариф не Pro
Храните API-ключ в секрете. Не передавайте его в URL-параметрах. При компрометации — немедленно перегенерируйте через AdminPanel.

Лимиты запросов

Каждый API-ключ ограничен 60 запросами в минуту. При превышении возвращается статус 429 Too Many Requests.

Каждый ответ содержит заголовки:

X-RateLimit-Limit: 60
X-RateLimit-Remaining: 58

При превышении лимита дополнительно возвращается заголовок Retry-After (секунд до сброса) и тело:

{
  "error": "Too Many Requests",
  "message": "Rate limit exceeded. Maximum 60 requests per minute.",
  "retry_after": 42  // секунд до сброса
}

Мутирующие эндпоинты (POST) дополнительно ограничены 20 запросами в минуту.

Формат ошибок

Все ошибки возвращаются в одном формате:

{
  "error": "Краткое название",
  "message": "Подробное описание ошибки"
}

При ошибках валидации (422) добавляется поле errors:

{
  "message": "The given data was invalid.",
  "errors": {
    "customer.phone": ["Укажите телефон"],
    "start_time": ["Нельзя записаться на прошедшее время"]
  }
}

Коды HTTP

200Успешно
201Ресурс создан
204Успешно, тело пустое
401Неверный или отсутствующий API-ключ
403Недостаточно прав (тариф, подписка, лимиты плана)
404Запись не найдена
409Конфликт (слот занят, дубль телефона)
422Ошибки валидации или недопустимое действие
429Превышен лимит запросов
500Ошибка сервера

GET /bookings/{id} Одна запись по ID

Параметры пути

ПараметрТипОписание
iduuidreqUUID записи

Ответ 200

{ "data": { /* объект записи, аналогично списку */ } }
404Запись не найдена
POST /bookings Создать запись
Лимит: 20 запросов в минуту (дополнительно к общему лимиту 60/мин).

Тело запроса (JSON)

ПолеТипОписание
service_iduuidreqUUID услуги
start_timedatetimereqISO 8601, должно быть в будущем
master_iduuidoptUUID мастера. Если не указан — подбирается автоматически
customer.namestringreqИмя клиента (макс. 255 символов)
customer.phonestringreqТелефон клиента (макс. 20 символов)
customer.emailemailoptEmail клиента
notesstringoptЗаметки (макс. 1000 символов)

Пример запроса

curl -X POST "https://yakut54.ru/api/v1/bookings" \
     -H "X-API-Key: ваш-ключ" \
     -H "Content-Type: application/json" \
     -d '{
       "service_id": "uuid-услуги",
       "start_time": "2025-06-01T10:00:00Z",
       "customer": {
         "name": "Иван Иванов",
         "phone": "+79001234567"
       }
     }'

Ответ 201

{
  "message": "Booking created successfully",
  "data": { /* объект записи */ }
}
409Слот занят или нет свободных мастеров на это время
422Ошибки валидации
PATCH /bookings/{id}/status Изменить статус записи

Допустимые переходы статусов:

pending   → confirmed   (подтвердить)
confirmed → completed   (завершить)

Для отмены используйте DELETE /bookings/{id}.

При подтверждении и завершении клиент получит уведомление в Telegram/MAX, если он их подключил.

Тело запроса (JSON)

ПолеТипОписание
statusstringreqconfirmed или completed

Ответ 200

{
  "message": "Booking status updated to confirmed",
  "data": { /* обновлённый объект записи */ }
}
422Недопустимый переход статуса
404Запись не найдена
DELETE /bookings/{id} Отменить запись

Отменяет запись. Можно отменить только pending или confirmed записи.

Клиент получит уведомление в Telegram/MAX, если подключён.

Ответ 200

{
  "message": "Booking cancelled",
  "data": { /* объект записи со статусом cancelled */ }
}
422Запись уже отменена или завершена
404Запись не найдена

Возвращает свободные временные слоты для выбранной услуги и даты. Используйте перед созданием записи.

Query-параметры

ПараметрТипОписание

datestringreqДата (YYYY-MM-DD)
master_iduuidoptUUID конкретного мастера (иначе — все доступные)

Ответ 200

{
  "data": [
    {
      "time": "10:00",
      "datetime": "2025-06-01T10:00:00+03:00",
      "master_id": "uuid",
      "master_name": "Анна"
    }
  ]
}

GET /categories Дерево категорий

Возвращает все корневые категории с вложенными подкатегориями и количеством товаров. Пагинации нет — возвращается полное дерево.

Ответ 200

    {
      "id": "uuid",
      "name": "Услуги",
      "products_count": 5,
      "children": [

}

PATCH /masters/{id} Обновить мастера
При деактивации мастера (is_active: false) все его будущие записи автоматически переназначаются или отменяются с уведомлением клиентов. При реактивации — восстанавливаются скрытые слоты.

Передавайте только те поля, которые нужно изменить (partial update).

Тело запроса (JSON)

ПолеТипОписание

phonestringoptТелефон
